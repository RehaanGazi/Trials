# Teacher Focus Mode — coverage map (v2)

The two handwritten pages supplied on 21 October 2026 are the focus outline. They are not a verified copy of the exam paper. The main course bank remains **354 original questions** across all six PDFs/PPTX files. This focus overlay adds **61 short applied practice questions** and selects **123 unique original questions**, yielding **184 unique focused questions** across **20 topic groups**.

## Page 1 — CSS

- CSS: definition, purpose, CSS rule structure and syntax.
- Three specific selectors: element (`p`), class (`.class`), ID (`#id`).
- Applying CSS: inline (`style` attribute), internal (`<style>`), external (`<link>`).
- CSS box model and diagram: content, padding, border, margin, and simple size questions.
- CSS 2D transforms: rotate, scaleX, scaleY, translateX, skew. Also practice **linear and radial gradients** because the handwritten note reads “2D transforms or CSS gradients.” No claim is made about which option will appear.

## Page 1 — JavaScript

- JavaScript definition, roles, script position/structure, basic code and `console.log`.
- JavaScript output: `getElementById`, `innerHTML`, `document.write`, alert and console.
- Given a JavaScript snippet, predict its output.
- Conditional statements (`if`, `else`, `else if`) with examples.
- JavaScript loops (`for`, `while`, `do...while`) and examples.
- A `switch` statement program with cases, `break` and `default`.

## Page 2 — JavaScript and HTML

- Declaring arrays and accessing elements.
- JavaScript functions and calling them.
- The DOM: definition and purpose.
- Find syntax or logical errors in JavaScript code, including punctuation and semicolon subtleties.
- Write code that displays a message in a paragraph.
- Lowercase and uppercase letter examples (a/A), JS case-sensitivity and case conversion.
- HTML lists and tables: write simple, complete code examples.

## Cautious interpretation of handwriting

- The “message in paragraph” and “capital alphabet” items are somewhat unclear, so this site includes likely short exercises instead of asserting an exact teacher instruction.
- A short line that resembles “paper flow” cannot be read confidently. It is *not* treated as a definite new syllabus topic. Clarify with the teacher if necessary.
- Although one line may say “Java program using switch,” it appears within the JavaScript section of the WDC list. The website practices **JavaScript switch**; it does not assume Java is a separate WDC topic.
